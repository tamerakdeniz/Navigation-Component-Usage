# 🧭 Navigation Component Usage

A sample Android project demonstrating the implementation of Android Navigation Component with modern Android development practices.

## 🎯 Project Overview

This project showcases the usage of Android Navigation Component, including:

- 🔄 Bottom Navigation implementation
- 📱 Fragment transitions with data passing
- 💫 Custom animations
- 🗣️ Bottom Sheet Dialog integration

## 🛠️ Technical Stack

- 📱 Android SDK
- 🎯 Kotlin Programming Language
- 🔧 Gradle Build System with Kotlin DSL
- 📦 AndroidX Navigation Component
- 🔄 View Binding
- 💡 Material Design Components

## ✨ Key Features

### 🎯 Main Page

- Navigation between fragments using Bottom Navigation
- Data passing between fragments using Safe Args
- Lifecycle awareness with logging

### ⚙️ Settings Page

- Bottom Sheet Dialog implementation
- Custom animations
- Interactive UI elements

### 📋 Detail Page

- Data reception from Main Page
- Custom back press handling
- Dynamic content display
